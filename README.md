# Student Record Management System

## Codomax Digital Solutions – Module 2

A beginner-friendly Python command-line application for managing student records.

### Features

- Add student records
- View all students
- Search students
- Update student records
- Delete student records
- Store records in CSV and JSON
- File handling using Python
- Exception handling with `try`, `except`, and `finally` concepts
- Functions with parameters and return values
- Lambda/list-comprehension concepts demonstrated in the project structure

### Technologies

- Python 3
- CSV
- JSON
- VS Code / Terminal

### How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python student_record_management.py
```

### CRUD Operations

The application supports:

- **Create** – Add Student
- **Read** – View/Search Students
- **Update** – Edit Student
- **Delete** – Delete Student

### Data Files

`students.csv` and `students.json` are included as sample data files. The application updates both files after CRUD operations.

### Learning Outcomes

This project demonstrates Python functions, file handling, CSV/JSON processing, exception handling, input validation, list comprehensions, and basic debugging practices.
